## Locked doctrine: Iteration Wallet

**NO DELETING FROM THE VAULT. EVER.**

Older Iteration Wallet files may contain language like `OPEN -> REMOVE -> DELETE`, `Removed_Files`, or deletion workflows. Those are now considered obsolete drift, contradiction, or incomplete early implementation, not the intended product truth.

Replace destructive vocabulary and behaviors with:

- Archive
- Retire
- Hide
- Supersede
- Copy Out
- Restore
- Promote Contender

The Vault is a protected memory and canonical-state system. Files in the Vault must not be batch-deleted, auto-deleted, overwritten, or silently replaced. Promotion should be explicit, typed, auditable, and reversible by archived evidence.

### Promotion doctrine

A promotion flow should require:

1. A user-selected or nominated contender.
2. A clear diff / comparison / evidence view.
3. Explicit confirmation, preferably typed `PROMOTE`.
4. Old canonical archived, never deleted.
5. New contender promoted with audit log and hash evidence.

## Locked doctrine: Oubliette

Oubliette is PubCast's protected intake vault for assets/files/code that the system cannot yet safely understand.

Oubliette is where unknown files go before they are trusted.

Rules:

- preserve original untouched
- hash the original
- probe/classify before use
- do not execute unknown code blindly
- do not mutate live PubCast state from untrusted intake
- do conversion and bridge testing only on copies
- record provenance, probe output, and clearance status
- release only cleared derivatives into live PubCast workflows

Short doctrine line:

> Oubliette is where forgotten files go to be remembered properly.

## Bridgewright / Adaptive Format Bridge System

Bridgewright is the system that helps PubCast handle unfamiliar formats safely.

Flow:

1. Unknown file arrives.
2. Oubliette preserves, hashes, and quarantines it.
3. Local probe identifies likely container/codec/source app.
4. Bridgewright searches trusted bridge strategies.
5. A recipe is created against copies only.
6. The conversion is tested and verified.
7. The recipe, output, logs, and original hash are stored.
8. A cleared derivative can enter PubCast.

Trust order:

1. built-in FFmpeg/GStreamer/libVLC style toolchains
2. official documentation
3. mature open-source libraries
4. package-manager-installable tools
5. community/forum clues only as investigation leads

Never auto-install random binaries/codecs/scripts just because a format is unknown.

## Universal Phone Audio Intake

PubCast should expect real-world audio from phones, recorders, old apps, and mixed ecosystems.

Target intake examples:

- `.m4a`
- `.aac`
- `.mp3`
- `.wav`
- `.aiff` / `.aif`
- `.caf`
- `.alac`
- `.flac`
- `.ogg`
- `.opus`
- `.webm audio`
- `.amr`
- `.awb`
- `.3gp` / `.3gpp`
- `.3g2`
- `.mka`
- `.mkv audio`
- `.wma`
- `.ape`
- `.mid` / `.midi`
- old ringtone/voice-note formats where practical

Internal working-master rule:

- keep original untouched
- create normalized working master as WAV/PCM or FLAC
- prefer 48 kHz for production workflows
- preserve channels and metadata when possible
- link derivative to original hash
- avoid unnecessary lossy re-encoding

Direct every-format-to-every-format conversion is not required. Decode to internal truth copy, then export.

## Interrupted Estate visual doctrine

The style name is **Interrupted Estate**.

Core formula:

> Gatsby opulence + Neo Art Deco + Star Trek-informed ergonomic intelligence + distressed aged grandeur + interruption, mending, patching, improvisation, and repair.

Important correction:

This is not Star Trek technology. It is technology with Star Trek confidence.

Star Trek influence means swagger, clarity, usability, and ergonomic intelligence — not seamless magic floating blue-light antigravity. PubCast machines should usually remain mechanically legible.

Principle:

> The miracle is real, but the mechanism remains visible.

Interrupted Estate is:

- beautiful but not sterile
- expensive but not untouched
- old but not dead
- modern but not plastic
- broken down but not poor
- repaired but not ashamed
- rich, but you might want to wash your hands after touching it

### Public side

Rooms, consoles, machinery, studios, salon spaces, writer rooms, control surfaces, drones, stage apparatus.

Materials and motifs:

- walnut/oak/dark wood
- brass/bronze/gold accents
- cream, green, leather, velvet, patinated metal
- Deco geometry
- tactile control surfaces
- visible seams, panels, retrofits, replacement parts
- repaired luxury, not clean showroom luxury

### Private side

Glass, residue, sunrise, old water, compressed flowers, relics, memory, light through damage.

Reference philosophy:

> beauty under pressure, altered by time, made more specific by imperfection, and illuminated through damage, residue, and constraint.

## Drone camera doctrine

The ornate camera apparatus is not just a tripod camera; it is a deployable flying drone.

Modes:

- Landed mode: tripod legs down, formal interview/studio camera posture.
- Flight mode: legs retract, wings/fan housings deploy, underside engine engages.
- Dock mode: folded in cradle, charging/syncing.
- Maintenance mode: panels open, fans/hinges/contacts visible.

Design rules:

- not antigrav
- not invisible propulsion
- not perfectly silent magic hovering
- not smooth featureless sci-fi plastic
- visible fans/propellers in deployable wings
- quiet because well-engineered, not because mechanism vanished
- ornate and functional
- advanced beyond classic steampunk while still visibly mechanical

Summary line:

> It does impossible-seeming things, but it still looks like a machine that earns them.
